# Walter Projects Glass & Aluminium Website

A responsive single-page website for Walter Projects Glass & Aluminium in Zimbabwe.

## Features
- Services, company overview, project enquiry steps and contact information
- Responsive mobile navigation
- Quotation form that prepares a WhatsApp message (customers review and send it themselves)
- Email fallback
- Guided project assistant demo; it is **not a live AI model** and does not save conversations
- SEO title, description and mobile theme metadata

## Deploy to Render as a Static Site
1. Open Render and select **New +** → **Static Site**.
2. Connect GitHub and select `beaven-maker/walter-projects-website`.
3. Set the branch to `main`.
4. Set **Build Command** to blank (or leave it empty).
5. Set **Publish Directory** to `.` (a single dot).
6. Click **Create Static Site** and wait for deployment.
7. Open the Render URL shown on the service dashboard.

No environment variables are required for this static version.

## Important notes
- The quote form opens WhatsApp; it does not upload photos, send messages automatically, or store enquiries on a server.
- The assistant is a guided demo, not a connected AI API. A real AI assistant requires a backend service and securely configured API key.
- The visual glass panels are CSS illustrations, not photographs of completed projects.
- Confirm all specifications, safety requirements, pricing and installation details directly with the business.
